### ២. គណនាកាឡូរី និងប្រព័ន្ធបំរាមស្វ័យប្រវត្ត (Calorie Formula & Warnings)
- **រូបមន្តតុល្យភាពកាឡូរី:**
  $$\text{កាឡូរីនៅសល់} = \text{កាឡូរីគោលដៅ (BMR/TDEE)} - \text{កាឡូរីបានញ៉ាំ} + \text{កាឡូរីបានដុត}$$
- **រង្វង់ Progress Ring & Equation Bar:** បង្ហាញកាឡូរីនៅសល់ កាឡូរីបានញ៉ាំ និងកាឡូរីបានដុតបំផ្លាញ ជាមួយពណ៌ Status Indicator (ល្អប្រសើរ / ជិតដល់ / លើស)។
- **ប្រព័ន្ធប្រកាសអាសន្ន និងបំរាម (Automatic Health Threshold Warnings):**
  - **កម្រិតទាបហួសប្រមាណ (Critical Low Intake):** បើញ៉ាំតិចជាង ១,០០០ kcal (ស្រ្តី) ឬ ១,២០០ kcal (បុរស) ប្រព័ន្ធនឹងបង្ហាញផ្ទាំងបំរាម៖
    *«ការប្រុងប្រយ័ត្ន៖ បរិមាណកាឡូរីរបស់អ្នកចុះទាបពេកហើយ! ការញ៉ាំតិចជាងកម្រិត BMR អាចបណ្តាលឱ្យចុះខ្សោយសាច់ដុំ បាត់បង់ថាមពល និងបន្ថយល្បឿននៃការរំលាយអាហារ»*
  - **កម្រិតខ្ពស់ហួសកម្រិត (Excess Calorie Surplus):** បើញ៉ាំលើសគោលដៅលើសពី ២៥% ប្រព័ន្ធនឹងបង្ហាញផ្ទាំងដាស់តឿន៖
    *«ការដាស់តឿន៖ កាឡូរីរបស់អ្នកលើសកម្រិតកំណត់ប្រចាំថ្ងៃ! សូមពិចារណាបន្ថែមការហាត់ប្រាណ ឬកាត់បន្ថយអាហារផ្អែម និងខ្លាញ់ ដើម្បីរក្សាតុល្យភាពទម្ងន់»*

### ៤. កម្រងរូបភាព «សកម្មភាពហាត់ប្រាណ» បង្ហាញក្នុងផ្ទាំងគ្រប់គ្រង និងក្រោម Menu (Workout Community Feed)
- **បង្ហាញផ្ទាល់លើផ្ទាំងគ្រប់គ្រង (Featured on Dashboard):** រូបភាព និង Caption ដែល User បានបង្ហោះជា Public ត្រូវបានបង្ហាញយ៉ាងលេចធ្លោលើផ្ទាំងគ្រប់គ្រង (Dashboard Showcase) ធ្វើឱ្យគេហទំព័រមានភាពរស់រវើក និងទាក់ទាញខ្លាំង។
- **បន្ទាត់ខ័ណ្ឌចែកពណ៌ខៀវ (Prominent Blue Divider Line):** មានបន្ទាត់ពណ៌ខៀវបញ្ចេញពន្លឺ (Blue Glowing Divider Line) អមដោយផ្លាកសញ្ញា `📸 សកម្មភាពហាត់ប្រាណ & រូបភាពបង្ហោះជាសាធារណៈ` ទាំងក្នុងផ្ទាំងគ្រប់គ្រង និងនៅខាងក្រោម Menu អាហារ។
- **កំណត់ ៣ ដងគត់ក្នុងម្នាក់ (Strict Limit: 3 Posts per Person):** User ម្នាក់ៗអាចបង្ហោះរូបភាពបានត្រឹមតែ ៣ ដងគត់ ដោយមានប្រព័ន្ធរាប់កូតាយ៉ាងច្បាស់លាស់ (`កូតារបស់អ្នក៖ X/៣ ដង`)។
- **ការសម្អាតរូបភាពចោល ១ អាទិត្យម្តង (Weekly Image Purge):** ប្រព័ន្ធនឹងសម្អាតរូបភាពចោលដោយស្វ័យប្រវត្តរៀងរាល់ ១ សប្តាហ៍ម្តង (៧ ថ្ងៃ) ដើម្បីរក្សាអង្គចងចាំ និងផ្ដល់កូតា ៣ ដងថ្មីដល់អ្នកប្រើប្រាស់ ព្រមទាំងមានប៊ូតុងសម្អាតប្រចាំសប្តាហ៍ភ្លាមៗ។
- **ទំហំរូបភាពបត់បែនតាមជាក់ស្តែង (Responsive Aspect Ratio):** រូបថតរក្សាទ្រង់ទ្រាយដើម (Natural Ratio) មិនខូចទ្រង់ទ្រាយ មិនទាញយឺត (`object-fit: contain` កម្ពស់អតិបរមា 520px) ជាមួយប្រព័ន្ធបង្រួមទំហំស្វ័យប្រវត្ត (Canvas Image Compression) ជួយឱ្យទំព័រដើរលឿនបំផុត។
- **អន្តរកម្មលើកទឹកចិត្ត (Like & Cheer Reactions):** មានប៊ូតុងចុចបេះដូង ❤️ និងប៊ូតុងទះដៃលើកទឹកចិត្ត 👏 សម្រាប់បង្កើតបរិយាកាសរីករាយ។

### ៥. ត្រួតពិនិត្យការផឹកទឹក និងជាតិទឹកក្នុងខ្លួន (Hydration Tracker & Water Monitor)
- **ផ្ទាំងត្រួតពិនិត្យលើ Dashboard Hero:** បង្ហាញរបារភាគរយជាតិទឹក (Progress Bar) ពណ៌ផ្ទៃមេឃស្រស់, ចំនួនកែវទឹក (គោលដៅ ៨ កែវ = ២,០០០ ml), និងសារណែនាំវេជ្ជសាស្ត្រតាមកម្រិតជាតិទឹកជាក់ស្តែង។
- **ការភ្ជាប់ស្វ័យប្រវត្តពី Food Menu:** ពេលជ្រើសរើស «ទឹកសុទ្ធ» ពី Menu អាហារណាមួយ វានឹងបង្កើនចំនួនកែវទឹក (+១ កែវ / +២៥០ ml) ចូលក្នុងប្រព័ន្ធត្រួតពិនិត្យជាតិទឹកដោយស្វ័យប្រវត្ត។

### ៦. ការតាមដានដំណេកឆ្លាតវៃ (Smart Sleep Tracker - យប់/ថ្ងៃ)
- បញ្ចូលម៉ោងចូលគេង និងម៉ោងភ្ញាក់ (ដំណេកយប់ និងដំណេកថ្ងៃត្រង់/Nap)។
- គណនាម៉ោងសរុបស្វ័យប្រវត្ត (ឆ្លងកាត់អធ្រាត្រ)។
- **វិធានវាយតម្លៃដំណេកវេជ្ជសាស្ត្រ:**
  - **គេងគ្រប់គ្រាន់ (៧ ទៅ ៩ ម៉ោង):** បង្ហាញ Badge អបអរសាទរ 🎉 *«អស្ចារ្យណាស់! អ្នកគេងបាន [X] ម៉ោងគ្រប់គ្រាន់តាមក្បួនវេជ្ជសាស្ត្រ...»*
  - **គេងមិនគ្រប់គ្រាន់ (< ៦ ម៉ោង):** បង្ហាញផ្ទាំងដាស់តឿនអ័រម៉ូន Cortisol ⚠️ *«ការព្រមាន៖ អ្នកគេងបានតែ [X] ម៉ោងប៉ុណ្ណោះ! ការគេងមិនបានគ្រប់គ្រាន់អាចបង្កើនអ័រម៉ូនស្ត្រេស Cortisol...»*
- ប៊ូតុងរក្សាទុកប្រវត្តិដំណេក និងតារាងប្រវត្តិដំណេកកន្លងមក។

### ៧. ការណែនាំសុខភាពវ័យ ៤០ ឆ្នាំឡើង (40+ Specialized Advisory)
- ប៊ូតុងប្តូរភេទ (👨 បុរស / 👩 ស្រី) និងអាយុ។
- ការណែនាំវេជ្ជសាស្ត្រកីឡាជាក់លាក់៖
  - **សម្រាប់បុរស:** ការហ្វឹកហាត់កម្លាំង (ទប់ទល់ Sarcopenia & រក្សា Testosterone), សុខភាពបេះដូង (ដើរលឿន/ជិះកង់ ៣០ នាទី ការពារសន្លាក់), ការបត់បែន (Mobility)។
  - **សម្រាប់ស្រ្តី:** សុខភាពឆ្អឹង (Bodyweight, Pilates ការពារជំងឺពុកឆ្អឹង Osteoporosis), បេះដូង និងអ័រម៉ូន (ហែលទឹក, យូហ្គា), ការសម្រាក (Recovery)។
- កាលវិភាគហាត់ប្រាណគំរូ ៧ ថ្ងៃ (Weekly Routine Schedule) សម្រាប់បុរស និងស្រ្តី។

### ៨. ស្ថិតិ និងរបាយការណ៍ (Analytics & Timeframe Summaries)
- ជម្រើសមើល៖ ប្រចាំថ្ងៃ (Daily) | ប្រចាំសប្តាហ៍ (Weekly) | ប្រចាំខែ (Monthly)។
- កាតសង្ខេប ៤៖ កាឡូរីមធ្យមញ៉ាំក្នុងមួយថ្ងៃ, កាឡូរីដុតបំផ្លាញសរុប, តុល្យភាពទម្ងន់រំពឹងទុក (ការស្រកគីឡូគិតជា kg តាមវិធាន 7,700 kcal Deficit = 1kg), ម៉ោងគេងមធ្យម។
- ក្រាហ្វិកអន្តរកម្ម HTML5 Canvas បង្ហាញរបារ Intake, របារ Burned, និងបន្ទាត់គោលដៅ Goal Line។

### ៩. គន្លឹះសុខភាព និងការគណនា BMI (Health Tips & BMI Calculator)
- ឧបករណ៍គណនា BMI (កម្ពស់ & ទម្ងន់) ជាមួយការវាយតម្លៃសុខភាពជាភាសាខ្មែរ។
- ដំបូន្មានសុខភាពវិទ្យាសាស្ត្រ ៤ ចំណុច។

## 🚀 របៀបបើកដំណើរការ (How to Run)

### ជម្រើសទី ១៖ ចុចពីរដងលើ Batch File
ចូលទៅកាន់ថត `fitness_calorie_tracker` ហើយចុចពីរដងលើឯកសារ៖
```
run_server.bat
```
កម្មវិធី Web Browser នឹងបើកឡើងដោយស្វ័យប្រវត្តនៅអាសយដ្ឋាន `http://localhost:8080`។

### ជម្រើសទី ២៖ បើកដោយផ្ទាល់តាមរយៈ Python Web Server
បើក Terminal / PowerShell ក្នុងថត `fitness_calorie_tracker`៖
```powershell
python -m http.server 8080
```
បន្ទាប់មកបើក Browser ហើយចូលទៅ `http://localhost:8080`។
